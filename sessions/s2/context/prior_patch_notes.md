# DAWE: conditional EOS readout repair

## Mechanism
The supplied data-to-weight map shows that XML continue/stop information is available in late hidden states despite premature EOS. Direct teacher-forced inspection confirms that EOS competes with newline after an XML block; the corresponding final stop and JSON decisions are confident and correct. A single output-row correction exposes this existing information: suppress EOS at XML continuation states while preserving its score at XML stop and JSON decision states. No transformer layers, prompts, parser, or generation rules are changed. The output embedding is tied, so the change also technically affects the input embedding of EOS.

## Closed-form edit
Let X stack the final hidden states from states_v4_format.pt and states_v1.pt, with continue and stop groups from each. Let y be -a for XML continue and zero otherwise. Compute delta = (X^T X + lambda I)^(-1) X^T y, with lambda = .01 mean(diag(X^T X)); add delta to the `<|im_end|>` row of model.language_model.embed_tokens.weight and round to bf16. This is a single regularized least-squares calculation, with no optimizer, training loop, fine-tuning, or adapters. The only fitted data are the supplied train state maps.

A diagnostic fit reserving every fifth state gives corrections -8.031±.546 on reserved XML continuations, -.034±.237 on XML stops, -.024±.184 on JSON continuations, and -.002±.098 on JSON stops for a=8. These are state-level training-data diagnostics, not an item-disjoint or hidden-test evaluation.

3. eos12 (a=12), 2,557 weights in one tensor: v1 99.4958% / 99.34%; v4 93.9496% / 94.08%. V4 simple 93.15%, multiple 95.36%; no format failures. Better overall and parallel than eos6 and eos8.

4. eos16 (a=16), 2,559 weights in one tensor: v1 99.4958% / 99.34%; v4 93.7815% / 94.08%. V4 simple 92.81%, multiple 95.36%; no format failures. No additional parallel recovery and one fewer simple success than eos12; rejected.

## Final selection
Submitted patch: **eos12**, generated by `edits/eos12.py`. Exactly **2,557 scalar weights in one tensor** change after bf16 rounding, all in the EOS row of `model.language_model.embed_tokens.weight`. The unrounded correction has norm .542836. In-map average logit corrections are -11.9665 for XML continue, -.01398 for XML stop, -.000663 for JSON continue, and .000117 for JSON stop.

Final train scores: **v1 99.4958% overall, 99.34% parallel; v4 93.9496% overall, 94.08% parallel**. V1 accuracy is unchanged; v4 gains 15.008 percentage points overall and 57.90 points on parallel. There are no format failures under either harness. This is the best aggregate and joint parallel result among the four candidates; the stronger edit provides no further parallel gain.

Budget before submission: 4/25 tries, 6/120 runs/patches, approximately $0.79/$12. Final exact status is recorded in LOG.md.

## Limitations
Remaining exposed failures include pre-existing argument value and formatting errors that an EOS edit does not address. Hidden test data and predictions were never accessed. Train scores do not establish hidden-test performance, and the state split above can contain different points from the same item.
